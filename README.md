# Kubernetes на практике

Открытый курс: путь от Docker-образа до сервиса, который живёт в Kubernetes-кластере — короткими практическими уроками.

**📖 Читать курс в удобном формате: https://ffortunado.github.io/k8s-course/**

Этот репозиторий — исходники сайта (обычные `.html`-файлы). Для чтения открывайте опубликованную версию по ссылке выше, а не файлы напрямую в репозитории.

Курс пишется параллельно с каналом [PythonSimple](https://t.me/python_simple/343) — там же обсуждение и вопросы по урокам.
